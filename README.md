# Himanshu's Portfolio

A premium, interactive developer portfolio built with Next.js, featuring high-end animations, glassmorphic UI elements, and a responsive horizontal scrolling showcase.

🔗 **Live Site:** [https://devportfolio-beta-six.vercel.app/](https://devportfolio-beta-six.vercel.app/)

---

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, Framer Motion
- **Animations:** GSAP (GreenSock Animation Platform) & ScrollTrigger
- **Visuals:** Rive (Interactive Vector Animations)
- **Deployment:** Vercel

---

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## 📂 Project Structure

- `src/components/` - Interactive components including Hero, Projects (GSAP-pinned horizontal layout), and Contact sections.
- `public/` - Media assets, interactive Rive animations, and resume.
